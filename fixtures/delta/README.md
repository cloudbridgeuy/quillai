# Delta fixtures

Generated by `quill-delta` 5.1.0 (`cd app && bun run fixtures:delta`). Do not hand-edit.
Replayed in JS by `app/src/delta_fixtures/delta_fixtures.test.ts`; a Rust Delta crate must reproduce every `expected`.

Each file is an array of `{ name, input, expected }`. Deltas use Quill wire JSON `{ "ops": [...] }`.

| File | input | expected |
|------|-------|----------|
| compose.json | `{a, b}` | `a.compose(b)` |
| transform.json | `{a, b, priority}` | `a.transform(b, priority)` |
| transform_position.json | `{delta, index, priority}` | integer from `delta.transformPosition(index, priority)` |
| invert.json | `{change, base}` | `change.invert(base)` |
| diff.json | `{a, b, cursor?}` | `a.diff(b, cursor)` |

## Length semantics (important for Rust)

quill-delta counts text length in **UTF-16 code units**, not bytes, chars, or graphemes.
`"😀"` has length 2, `"👨‍👩‍👧"` has length 8, `"日"` has length 1. Embeds (object inserts) have length 1.
All `retain`/`delete` counts and `transformPosition` indexes are in these units, so a Rust implementation must count/split strings by UTF-16 units
(splitting inside a surrogate pair is possible in JS; fixtures avoid relying on that where practical).
