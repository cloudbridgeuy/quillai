Static rebuild of the lost mockup for the owner's 2026-11-10 decision (GUZ-1566 spec, GUZ-1567..1571 builds, epic GUZ-1434). This is the current reference for the editor header and rails. It replaces the save status label and the word, character and line counts that older mockups drew above the page. Nothing here is wired; hover and open states are drawn. Sample text is invented.

1 · Default

The header shows only where you are: series › book. There is no save label while saving works, no counts and no model label. Continue is an icon button like the others; its name and key are in the tooltip (drawn here as on hover). The "?" Help button sits above the gear.

Header: path "series › book", 12px --graphite, centred above the sheet. No save label, no counts, no model label. Right rail, top to bottom: Continue · Edit selection · Dialogue · Continue window · (gap) · Help "?" · Settings. All 36px icon buttons. Continue tooltip: "Continue" + key chip. No visible label and no key chip on the rail. Open (GUZ-1566): where "Saving…", "Stop" and the cut-off badge go once Continue has no label. Not drawn here.

2 · Help open

Help explains the page and holds what left the header. Three sections: the marks you can see on the page, the tools with their keys, and "This chapter" with the counts and the Continue model, with a link to change it.

Help pane: same shell as Settings (380px, right 56px, --panel-shadow). The "?" button is --pi-green while open. Esc, outside click or "?" close it. Marks on the page: one row per mark, drawn with the mark's own token. Tools: rail order, key chip on the right. This chapter: words, characters, lines · Continue model name · "Change" opens Settings → AI.

3 · Save failure

A red "Not saved" pill appears only when a save fails. It floats over the desk beside the path; the path and the sheet do not move. The reason is in its tooltip (drawn here as on hover). There is no Retry link.

Pill: shared Alert fail style · --alert fill · white text and dot · radius 999px · --fail-shadow. Sits 14px right of the path; the path stays centred. Tooltip and screen-reader description carry the unchanged detailed reason (editor-design.md, Saves). Open (GUZ-1566): whether the pill gets a Retry action. Not drawn.
