A · Drawer

"This chapter happens at" is a visible block at the top of Series lore. Each lore row says which state applies to the open chapter and since which point. The heading counts entries with a state here. New lore is the + in the heading, with a neutral hover.

Lore row: line 1 name 13px + kind 11px · line 2 11px: filled pip + state name + "since <point>", or dashed pip + "Base text" Count "3 of 5 entries": entries whose text differs from base at the open chapter's point. Changing the select re-reads every row. "No point (base text)" stays the first option.

B · Timeline

The timeline teaches the idea by showing it. Points run left to right in story order. Chapters sit under their point. Each lore entry has one bar per state, running until the next state. Click a bar to edit it. The arrows on a point move it left or right.

Columns: entry · No point (base text) · one per point. The open chapter's column is tinted and tagged. Bar: starts at the state's point, ends where the next state starts. Dashed bar = base text. Click opens Edit lore on that state. Point header: ‹ › move the point one place (replaces Move up / Move down). Rename and delete show on hover beside them.
