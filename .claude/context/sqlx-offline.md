# SQLx Compile-Time Query Checking

## How It Works

SQLx macro variants (`query!`, `query_scalar!`, `query_as!`) verify SQL at compile time against the database schema. For CI/builds without a live DB, the `.sqlx/` cache provides offline verification.

## Setup

1. **Cargo.toml features**: `sqlx = { features = ["runtime-tokio", "sqlite", "macros", "migrate"] }`
   - `macros` — enables `query!`/`query_scalar!` compile-time checking
   - `migrate` — enables migration support
   - Note: sqlx 0.8.x has no `"offline"` feature flag; offline mode is automatic with `.sqlx/` cache + `SQLX_OFFLINE=true`

2. **`.env`**: `DATABASE_URL=sqlite:quillai.db` — needed by `cargo sqlx prepare`

3. **`.sqlx/` directory**: Contains JSON query metadata generated by `cargo sqlx prepare --workspace`

## Regenerating the Cache

When SQL queries change:

```sh
cargo sqlx database create        # creates quillai.db if missing
cargo sqlx migrate run             # applies migrations
cargo sqlx prepare --workspace     # regenerates .sqlx/*.json
```

## Offline Builds

```sh
SQLX_OFFLINE=true cargo check -p quillai_api
```

## Important

- Use macro forms (`query_scalar!` not `query_scalar`) for compile-time checking
- `.sqlx/` directory **must** be committed to git (required for CI)
- `.env` and `*.db` are gitignored
- `.env.example` provides the template for local setup
