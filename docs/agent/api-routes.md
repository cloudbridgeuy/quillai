# API Routes

## API Routes

**Rust backend** (`crates/api/src/`):
- `GET /settings/ai`, `PUT /settings/ai` — Read or partially update AI `base_url`, `api_key`, `generate_model`, `edit_model`, `image_model`, `lore_complete_model`, and `dialogue_model` (200 JSON). Empty strings clear each saved value; omitted/null fields stay unchanged. Responses expose resolved `base_url`, `generate_model`, `edit_model`, `image_model`, `lore_complete_model`, `key_set`, and per-field `sources` (`base_url`, `api_key`, `generate_model`, `edit_model`, `image_model`, `lore_complete_model`; each `saved`, `env`, `none`; an env `QUILLAI_AI_MODEL` fills all three text models; `image_model` reads only `QUILLAI_AI_IMAGE_MODEL`, never `QUILLAI_AI_MODEL`). The old `model` field is rejected with 422, never the key. Invalid URLs (must be HTTP(S) with a host), whitespace-only models, or models outside a loaded file catalog (or of the wrong `kind`: text for generate/edit/lore_complete, image for image) return 422. Each request resolves saved values before environment values, independently per field; changes apply without restart.
- `GET /users` — List all users (JSON array)
- `POST /users` — Create user (201 + JSON)
- `GET /users/{id}` — Get user by ID (JSON or 404)
- `PUT /users/{id}` — Partial update user (JSON, 404, or 422)
- `DELETE /users/{id}` — Delete user (204 or 404)
- `GET /trash` — Explicitly deleted universes, containers, pieces and lore, newest first with type and ID tie-breaks. Each item has `type`, native `id`, `title`, `deletedAt`, `location` (nullable universe/series/book titles), `childCounts` (disjoint chapter/piece/lore descendants, including deleted rows), `deletedParents` (deleted ancestor titles), `resourcePath`, and `restoreAncestors` (paths to restore before an action). Lore actions require restoring its deleted universe first. Book series uses the legacy series path because permanent deletion may also delete an orphan universe and its lore; TV series uses the container path.
- `GET /activity?limit=N` — Return recently revised active leaf pieces, newest first (ties by piece ID descending). Default limit 20; valid range 1–50, invalid values return 422. Each entry has `pieceId`, `universeId`, `title`, `scriptTitle` (the parent script's title for script-format leaf pieces with a script parent; null otherwise), `label`, `format`, nullable `parentId`, UTC `changedAt`, and nullable `chapter` with `seriesId`, `bookId`, `chapterId`. Pieces without revisions and deleted items or descendants are omitted (200 JSON).
- `GET /tree` — Return `{series, universes}` with nested books, chapter summaries, containers, root pieces, and group children. Lists use position then ID order and omit deleted items and their descendants; piece content is omitted (200 JSON).
- `GET /series` — List series ordered by position, then ID (JSON array)
- `POST /series` — Create series with nonblank title and nonnegative integer position (201 + JSON or 422)
- `GET /series/{id}` — Get series by ID (JSON or 404)
- `PUT /series/{id}` — Partial update title and/or position (JSON, 404, or 422); omitted/null fields stay unchanged
- `DELETE /series/{id}` — Soft-delete series; `?permanent=true` permanently deletes it and its descendants (204 or 404)
- `POST /series/{id}/restore` — Restore hidden series and deleted universe ancestor (200 JSON or 404)
- `GET /series/{id}/books` — List books ordered by position, then ID (JSON array or 404 for missing series)
- `POST /series/{id}/books` — Create book with nonblank title and nonnegative integer position; parent from path (201 + JSON, 404, or 422)
- `GET /series/{id}/books/{book_id}` — Get book scoped to series (JSON or 404)
- `PUT /series/{id}/books/{book_id}` — Partial update title and/or position, scoped to series (JSON, 404, or 422); omitted/null fields stay unchanged
- `DELETE /series/{id}/books/{book_id}` — Soft-delete book scoped to series; `?permanent=true` permanently deletes it and its chapters (204 or 404)
- `POST /series/{id}/books/{book_id}/restore` — Restore hidden book and deleted ancestors (200 JSON or 404)
- `GET /series/{id}/lore` — List author lore ordered by name, then ID, including hidden notes (200 JSON array or 404 for missing series)
- `POST /series/{id}/lore` — Create lore with required kind (character/place/term/note) and nonblank name; optional fields retain migration defaults (201 + JSON, 404, or standard JSON 422 for invalid fields/types). Keywords/aliases are arrays of nonblank strings; pinned is boolean; level is include/known_dont_reveal/leave_out
- `GET/PUT /series/{id}/rules` — Prose rule settings `{language, rules}` (`docs/rules-engine.md`). GET returns the stored `rules` object without defaults. PUT takes `{language?, rules?}`; `rules` replaces the whole object and an omitted field is kept; returns the GET shape (200). Missing, deleted, deleted-universe or non-`book_series` id: 404. Malformed JSON: 400 `INVALID_JSON`. Non-object body, `language` not `en`/`es`, `rules` or an entry or its `params` not an object, `enabled` not boolean, `scope` not `narration`/`dialogue`/`both`, or a catalogue param out of range or malformed: 422 `VALIDATION_ERROR`. Unknown rule ids and param keys are kept.
- `GET /series/{id}/lore/{lore_id}` — Get author lore scoped to series, including hidden notes (200 JSON or 404)
- `PUT /series/{id}/lore/{lore_id}` — Partial lore update scoped to series (200 JSON, 404, or standard JSON 422); omitted/null fields unchanged, including pinned=false as an explicit update
- `DELETE /series/{id}/lore/{lore_id}` — Soft-delete lore scoped to series; `?permanent=true` permanently deletes active or deleted lore (204 or 404)
- `GET /series/{id}/books/{book_id}/chapters` — List chapters ordered by position, then ID; default returns only id, title, position, kind, head_rev without reading content or revisions. `?content=true` returns full chapters with book_id and rebuilt head content; any other supplied content value, including false or empty, returns 422 (JSON array, 404, or 422)
- `POST /series/{id}/books/{book_id}/chapters` — Create chapter with title, position, kind (chapter/prologue/epilogue), and optional Delta content; snapshot at revision zero (201 + JSON, 404, or 422). Delta input requires an object with an ops array and valid operations; omitted content defaults to an empty Delta
- `GET /series/{id}/books/{book_id}/chapters/{chapter_id}` — Get chapter rebuilt head content and head_rev, scoped to book and series (JSON or 404)
- `PUT /series/{id}/books/{book_id}/chapters/{chapter_id}` — Partial update title, kind, and/or position; omitted/null fields unchanged; any content key rejected (JSON, 404, or 422)
- `DELETE /series/{id}/books/{book_id}/chapters/{chapter_id}` — Soft-delete chapter scoped to book and series; `?permanent=true` deletes permanently (204 or 404)
- `POST /series/{id}/books/{book_id}/chapters/{chapter_id}/restore` — Restore hidden chapter and deleted ancestors (200 JSON or 404)
- `POST /series/{id}/books/{book_id}/chapters/{chapter_id}/deltas` — Submit `{baseRev, delta}`; transform against later retained revisions with server priority, append atomically, return `{rev, delta}` (200, 404, 409 unavailable/future history, or 422 malformed JSON/Delta or compose failure)
- `GET /series/{id}/books/{book_id}/chapters/{chapter_id}/deltas?since=rev` — Return missed revisions ordered ascending as `[{rev, delta}]`; current head returns `[]` (200, 404, 409 unavailable/future history, or 422 invalid query)
- `POST /series/{id}/lore/{lore_id}/restore` — Restore deleted lore (200 JSON or 404); deleted lore is excluded from list, get, and update
- Old `/series`, `/books`, `/chapters`, deltas, and lore routes are a façade over the story model with unchanged JSON: series are `book_series` containers, books are prose `novel` groups (id = `legacy_book_id`), chapters are their prologue/chapter/epilogue leaves (id = `legacy_chapter_id`), and series lore is the container's universe lore (shared by series in one universe). `POST /series` creates a universe plus container; soft-deleting a series preserves its universe and shared lore; permanent deletion also removes its universe and lore only when no containers or pieces remain, including hidden rows
- `GET/POST /universes`, `GET/PUT/DELETE /universes/{id}` — title/position, series rules (201, 404, 422); DELETE soft-deletes the universe; `?permanent=true` cascades containers, pieces, lore. `POST /universes/{id}/restore` restores a deleted universe
- `GET/POST /universes/{id}/lore`, `GET/PUT/DELETE /universes/{id}/lore/{lore_id}` — lore fields and deletion semantics as series lore, JSON `universe_id`; `POST /universes/{id}/lore/{lore_id}/restore` restores deleted lore
- Universe lore list, get, update and restore responses include `states`: the entry's active states `{id, name, pointId, visibleText, hiddenNotes}` ordered by point position, point ID, state ID (states on soft-deleted points are kept); create returns no `states`, and series lore responses never include them. `GET/POST /universes/{id}/lore/{lore_id}/states` list and create (201); `PUT/DELETE /universes/{id}/lore/{lore_id}/states/{state_id}` update and soft-delete (204); `POST .../states/{state_id}/restore` restores (200). Missing or deleted universe, entry (or entry in another universe) or state: 404. Blank name, or a point that is missing, deleted or in another universe: 422. A second active state of one entry on one point (create, update, restore): 409 `CONFLICT`. Deleting an entry hides its states; restoring it brings them back.
- `GET/POST /universes/{id}/containers`, `GET/PUT/DELETE /containers/{id}` — `{id, universeId, title, position, kind}`; `kind` or `universeId` on PUT is 422. DELETE soft-deletes the container; `?permanent=true` cascades its pieces. `POST /containers/{id}/restore` restores a hidden container and deleted universe ancestor
- `POST /universes/{id}/lore/{lore_id}/images` takes optional `{timelinePointId, purpose, timeOfDay}` and generates one image through OpenAI-compatible `POST {base_url}/images/generations` (`crates/api/src/ai/images.rs`, webp). The prompt uses the entry's visible text, or the active state's at that point; hidden notes are never sent and `leave_out` lore is 422. `purpose` is `portrait`, `profile`, `map` or `render`; `map` and `render` are for place entries only, and `timeOfDay` (`dawn`, `day`, `dusk`, `night`) is for `render` only (default `day`); other pairs are 422, and unknown values are 400. The prompt preamble follows the purpose (top-down illustrated map, establishing view plus a time-of-day clause); omitted purpose keeps the per-kind preamble and stores `portrait`. Size, quality and per-image `cost` come from the catalog image model (else `1024x1024`/`medium`, null cost). Returns 201 metadata `{id, loreEntryId, timelinePointId, purpose, timeOfDay, prompt, model, size, quality, mime, cost, createdAt}`. No image model: 503 `AI_NOT_CONFIGURED` naming `QUILLAI_AI_IMAGE_MODEL`; provider failure: 500 with the provider message; point not active in the universe: 422. `GET .../images` lists metadata by ID; `GET .../images/{image_id}` returns the bytes with the stored mime. Wrong universe, entry or image: 404.
- `GET/POST /universes/{id}/timeline` — active timeline points `{id, universeId, name, position}` ordered by position then ID; POST takes `{name, position}` (201; missing or deleted universe 404 like lore; blank name or negative position 422). `PUT /timeline/{id}` changes `name` and/or `position` (200, 404, 422). `DELETE /timeline/{id}` soft-deletes (204 or 404); `POST /timeline/{id}/restore` restores (200 or 404)
- `GET /universes/{id}/pieces?container=none` — loose roots; other or missing `container` is 422. `POST /universes/{id}/pieces` — root in storage `{title, position, label, shape, format?}`; format defaults to script for screenplay/tv_script/episode, else prose; a leaf starts with an empty Delta
- `GET/POST /containers/{id}/pieces` — root pieces; book_series allows novel/novella, tv_series tv_script/episode (422 otherwise)
- `POST /pieces/{id}/children` — new empty leaf under a group with the group's format; label defaults to chapter (prose) or scene (script); non-group is 422
- `GET/PUT/DELETE /pieces/{id}` — leaf adds `content`/`headRev`, group adds `children`; PUT changes title/position/label/format (group format cascades to children) and `timelinePointId` (number sets, null clears, absent keeps; 422 if the point is missing, deleted, or in another universe). Every piece JSON, including `/tree`, has `timelinePointId` (null when unset); `universeId`, `containerId`, `parentId`, `shape`, `content`, a child format change, or a membership break is 422
- `DELETE /pieces/{id}` — Soft-delete a piece; `?permanent=true` deletes it and its descendants permanently (204 or 404). `POST /pieces/{id}/restore` restores a hidden piece and deleted ancestors atomically (200 JSON or 404). Restore clears only markers on that ancestor path; independently deleted descendants stay hidden. Each cleared node appends after visible siblings in its universe, container, or parent; nodes without a deletion marker keep their position. A visible restore target returns 404. Hidden universes, containers, pieces, and their descendants return 404 on reads and writes; content and revisions stay through restore
- `GET /sync/events?pieceIds=12,13` — SSE stream for 1–256 distinct active leaf IDs; query limit 4096 bytes. Sends ready with pieceIds, changed with pieceId and rev, and resync after lag (404 or 422 before streaming). Reconnect and read delta history to repair missed events.
- `GET /series/{id}/books/{book_id}/chapters/{chapter_id}/events` — same SSE stream for the scoped chapter’s backing piece (404 if unavailable).
- `POST/GET /pieces/{id}/deltas` — leaves only (group 404); same JSON and 409 rules as chapter deltas
- `GET /pieces/{groupId}/scenes` — a script group opened in one GET: the group's piece fields plus `scenes: [{...piece, content, headRev}]`, every child in `position, id` order, each rebuilt like a leaf `GET /pieces/{id}` in one transaction (200, 404 missing, 422 for a leaf or a prose group)
- `GET /pieces/{groupId}/scenes/deltas?since=<sceneId>:<rev>,...` — one poll for a script group: `{children: [id...], scenes: {"<id>": {revisions: [{rev, delta}]} | {conflict: "future" | "unavailable"}}}`. `children` is the current order; `scenes` holds only the requested ids (empty `since=` asks for none). Per-scene leaf history rules; a scene with future/negative or missing history gets `conflict` and the others still return (200). A scene not in the group, a repeated id, a malformed or missing `since` is 422; missing group 404, leaf or prose group 422. Posts stay on `/pieces/{id}/deltas`
- `POST /pieces/{id}/placement` — `{containerId: number|null, position}`; a root moves to that container or storage (null); a child accepts only null (detach: clears `parentId`). Returns the piece detail (200, 404, or 422 for another universe, a missing container, a membership break, or a child with a container)
- `POST /pieces/{id}/split` — `{label?}`; a root leaf becomes the position-0 child of a new group that copies its universe, container, title, position, label, and format; child label defaults to chapter (prose) or scene (script). Returns the group detail with children (201, 404, or 422 for a group, a child, or an unknown label)
- `POST /pieces/{groupId}/attach` — `{pieceId, position}`; a root leaf in the same universe and format becomes a child of that group, clearing `containerId` in the same UPDATE. Returns the group detail (200, 404 for a missing group or hidden source, or 422 for a non-group target, a missing/group/child source, another universe, or another format)
- `POST /ai/generate` — Stream AI delta fragments as NDJSON; Continue removes a case-insensitive, whitespace-normalized overlap of at least 12 characters against the last 512 characters before the caret. Each request resolves saved provider fields before environment values. Optional `model` must exactly match an active catalog ID (422 if invalid) and takes priority; omission uses a valid saved model for the request's action (`generate_model`, `edit_model`, `lore_complete_model`, or `dialogue_model`), then the catalog's action default, then `QUILLAI_AI_MODEL`. `action: "image"` is rejected with 422 `action must be one of: generate, edit, lore_complete, dialogue`. Generate and edit require `document` (422 if missing). `action: "lore_complete"` (GUZ-1508) reads `loreComplete: {name, kind, text}` (unknown keys 422; `text` is the visible AI context before the caret, at most 65,536 UTF-8 bytes, else 422 before any provider call; blank `name` 422). The prompt (`crates/api/src/ai/lore_complete.rs`) holds the escaped name, kind, and text plus author guidance; other request fields except `model` (lore, document, story context, history, overrides, output token limit) are ignored, and output uses the default 512 tokens. `action: "dialogue"` (GUZ-1534) takes Continue's `document`, `selection`, `storyContext`, and `lore` plus `dialogue: {speakers, brief}` (unknown keys 422); 422 before any provider call when it is missing, speakers are empty, more than 6, duplicated, or not a `character` name in request lore, or `brief` exceeds 4,096 UTF-8 bytes. The prompt (`crates/api/src/ai/dialogue.rs`) holds the escaped speakers, brief, story context, lore, and only the text before the caret; output is fixed at 1,024 tokens. See [AI streaming context](../../.claude/context/ai-streaming.md)
- `GET /ai/models` — Return model IDs, labels, `kind` (`text` or `image`), input/output prices per million tokens for text models, `price_per_image` (USD), `size`, and `quality` for image models, and `defaults.generate` (Continue) / `defaults.edit` / `defaults.lore_complete` / `defaults.dialogue` IDs plus `defaults.image` when an image model is resolved. Null fields are omitted. Catalog files may omit `kind` (text); `defaults.image` is optional and must name an image model, while generate/edit defaults must name text models; optional `defaults.lore_complete` and `defaults.dialogue` must name text models and fall back to the generate default (never the image model). With a loaded file, preserve its list and action defaults unless a saved per-action model matches an entry, which replaces that action's default. Without a file, the saved `generate_model` (else `edit_model`) supplies the single entry; otherwise use the startup environment catalog. No provider configuration or `include_usage`; missing catalog returns 503 `AI_NOT_CONFIGURED`.
- `GET /settings/author-guidance` — Return `{text: string}`; missing row returns empty text (200).
- `PUT /settings/author-guidance` — Save `{text: string}` and return saved text (200); empty clears guidance, more than 65,536 UTF-8 bytes returns 422. Invalid JSON/types return the standard 400 JSON error.

**Bun frontend** (`app/src/index.tsx`):
- `GET /assets/*` — static file serving
- `GET /api/hello` — JSON hello
- `PUT /api/hello` — JSON hello (PUT)
- `GET /api/hello/:name` — parameterized JSON hello
- `GET /*` — SPA fallback to index.html
